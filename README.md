# Toronto Millworks

Marketing site for a custom millwork and cabinetry shop at 2585 Drew Rd, Mississauga,
serving everywhere within 120 km. Static HTML generated by Python, hosted on Vercel.

- Live: https://toronto-millworks.vercel.app
- Repository: https://github.com/ausystems/toronto-millworks
- Contract and acceptance criteria: [SPEC.md](SPEC.md) · SEO status: [SEO.md](SEO.md)

## Build and check

```bash
python3 scripts/build_site.py     # every page, sitemap, robots, llms files, redirects, headers
python3 scripts/audit.py          # the quality gate; must report 0 failures
node scripts/og_cards.mjs         # social cards for pages whose spec changed (needs Chrome)
node scripts/serve.mjs            # local server with production headers, redirects and 404s
node scripts/smoke.mjs           # after a deploy: crawls the live site, exits 1 on any failure
```

Requirements: Python 3.9+ with Pillow, Node 22+, Google Chrome for the social cards.
The CI gate lives in `ci/github-actions-quality.yml`. To switch it on, move it to
`.github/workflows/quality.yml`; pushing workflow files needs a GitHub token with the
`workflow` scope (`gh auth refresh -s workflow`), or add it through the GitHub web UI.

## Images

Every photograph on the site is a named plate in `PLATES` inside
`scripts/build_library.py`: a source image, a focal point, a crop size and alt text.
Run `python3 scripts/build_library.py` and each plate is cut into wide and tall
compositions at several widths, plus a 24 px blur-up placeholder.

To use real project photography, add a plate pointing at the new photo and use its
name in `scripts/pages.py` or a service's `plates` list in `site_content.py`. Where no
photo exists yet, pages show shop drawings instead; those can stay alongside photos.

## Before launch: facts only the business can supply

The generator leaves out anything that is empty rather than inventing it.

| Field in `site_content.py` | Why it matters |
|---|---|
| `email` | Unconfirmed. Every enquiry goes here. |
| `phone` | Adds a call button to the phone quote bar, the schema and the contact page. |
| `form_endpoint` | Formspree, Basin or similar. Without it the quote form composes an email instead. |
| `same_as` | Google Business Profile, Instagram, Houzz: strengthens local SEO. |
| `founded` | Founding year for the Organization schema. |

Reviews and ratings are deliberately absent until real ones exist.

## Deploy

Push to `main`; Vercel builds nothing and serves the generated files. `.vercelignore`
(generated from `seo.PRIVATE`) keeps scripts, sources and docs off the site. `vercel.json`
(generated) carries clean URLs, trailing slashes, redirects, cache rules and security
headers including a Content-Security-Policy.

Once the deployment is live, `node scripts/smoke.mjs` checks it end to end; run it
against `node scripts/serve.mjs` with `node scripts/smoke.mjs http://localhost:4180`.

## Measuring conversions

The site pushes events to `window.dataLayer`: `quote_click`, `email_click` and
`call_click` (with `cta_location` and `cta_text`), `quote_step` and
`quote_submit` (with `method`, `project` and `area`). Add Google Tag Manager,
GA4 or any tag that reads the dataLayer and they are collected; until then
nothing leaves the page. Set `form_endpoint` in `scripts/site_content.py` so
requests are delivered directly instead of through the visitor's email app.
